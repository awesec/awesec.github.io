measX / Emerson DASYLab DSB File Parsing Out-of-Bounds Read VulnerabilityAWE-2026-056

CVE ID CVE-2026-64198
Vendor measX / Emerson
Product DASYLab
Affected versions ≤ 2024 (17.0.0), Build 20
Patched version 2026.0.0 (Build 65)
Summary The affected application is vulnerable to an out-of-bounds read vulnerability when parsing user-supplied data, which may allow an attacker to execute arbitrary code. Successful exploitation requires an attacker to get a user to open a specially crafted DSB file.
