Fuji Electric TELLUS V9 File Parsing Use-after-Free VulnerabilityAWE-2026-084

CVE ID CVE-2026-107902
Vendor Fuji Electric
Product TELLUS
Affected version ≤ 5.0.5.0
Patched version 5.0.6.0
Summary A use-after-free vulnerability exists in TELLUS when parsing V9 files. The issue can potentially be exploited to execute arbitrary code, but requires a legitimate user to open a malicious V9 file.
